Server Fix

Only use this if the normal Hero Gallery capture cannot read your collection because your Mini Heroes region uses a different server.

Nothing done yet. Click a step when you finish it.

Do I need this?

Usually, no. Try 1 - CAPTURE MY COLLECTION.cmd first.

  • If it reaches SUCCESS, stop here. Your server is already supported.
  • Use Server Fix if the capture times out or reports that the game's server is refused/unsupported, especially outside the currently validated US server.
  • Server Fix changes only the exact server hostname the extractor is allowed to read. It does not loosen the proxy into a general tunnel.

What the server finder records

3 - DISCOVER REGIONAL SERVERS.cmd watches which MAX GAME hostnames the emulator asks to reach.

  • It records hostnames only in discovered-hosts.txt.
  • It does not decrypt HTTPS, install a certificate, or save requests, headers, tokens, account IDs, or response bodies.
  • It only forwards HTTPS to maxngame.com publisher hosts that resolve to public IPv4 addresses.
  • The normal roster extractor remains fail-closed: one exact hostname on port 443.

Local server converter

This works entirely on your computer. No file is uploaded anywhere.

3. Choose the server to try

If several hosts appear, start with the one associated with the login/title-screen run. The finder proves the game contacted a publisher hostname; it cannot prove which observed hostname carries the roster response.

Important: a discovered hostname is a candidate, not proof that it is the roster API. If the patched capture still fails, restore your original proxy.mjs and try another observed MAX GAME hostname. Do not add unrelated domains or wildcards.

Troubleshooting

The finder produced no hostnames

Run it again and make sure Mini Heroes starts fresh and you press Start while discovery is active. If the game was already fully signed in, it may not repeat the same login connections.

I see several maxngame.com hosts

That is possible. The finder intentionally does not inspect encrypted traffic, so it cannot label which hostname contains the roster response. Patch one candidate at a time; the normal extractor still allows exactly one selected host.

The converter says proxy.mjs is unsupported

Use the unmodified proxy.mjs supplied with this Hero Gallery version. The converter requires the exact export const API_HOST = '...'; setting so it can make one narrow change instead of rewriting arbitrary JavaScript.

Can I make the change manually?

Yes. Open tools\exporter\proxy.mjs in a text editor and change only the hostname inside export const API_HOST = '...';. Save the file as plain text. Do not add wildcards, extra domains, or change export.mjs/cert.mjs; they already import this one server setting.

My emulator network is broken after an interrupted run

Double-click 2 - RESTORE EMULATOR NETWORK.cmd. It restores the proxy values saved before the interrupted Hero Gallery run.
